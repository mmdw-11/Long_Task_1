**怎么看结果**

每个实验目录都有三个文件：

```text
summary.json  汇总指标
rows.jsonl    每条样本明细
report.md     人看的报告
```

最常看：

```powershell
Get-Content runs\experiments\workflow_300\summary.json
Get-Content runs\experiments\memory_engine_longmemeval\longmemeval\engine\summary.json
Get-Content runs\experiments\memory_mem0_longmemeval\longmemeval\mem0\summary.json
Get-Content runs\experiments\skills_skillevolbench_30\summary.json
```

**什么结果能说明你的项目有效**

最小有效证据链是：

1. workflow 编排实验：`pass_rate >= 0.95`，最好 `1.0`  
   证明你的编排框架可靠。

2. engine 记忆实验优于关闭 LLM judge：  
   `engine + llm_judge` 的 `pass_rate / avg_mrr` 高于 `engine --no-llm-judge`。  
   证明 DeepSeek 记忆更新判断有价值。

3. engine 记忆实验接近或超过 mem0：  
   如果你的 `avg_mrr` 接近 mem0，且耗时更低，这是很好的结果。  
   如果你的效果更高，那更强。

4. SkillEvolBench 小子集：`avg_coverage >= 0.7` 且 `avg_retrieved > 0`  
   证明技能生成、发布、检索、复用链路是通的。

5. 断点续跑有效：同一命令第二次运行出现 `already_complete` 或只补剩余样本。  
   证明实验可复现、可持续跑。

我建议你先按这个顺序跑：`workflow_300` → `memory_engine_limit20` → `memory_engine_no_llm_judge_limit20` → `mem0_limit20` → `skills_30`。小规模确认无误后，再把 `--limit` 去掉跑完整数据。
