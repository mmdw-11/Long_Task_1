```text
WORKING -> Python dict / LRU cache
TASK -> SQLite
PROJECT -> Markdown 原文 + SQLite 索引
GLOBAL -> SQLite / Redis / 可选 Mem0/Zep
```

第二版再扩展每层的内部路由：

```text
热数据：进程内 dict，最快，生命周期短。
温数据：Redis，适合多进程共享和 TTL。
冷数据：Markdown / JSONL 文件，适合人工可读、版本管理、审计。
结构化数据：SQLite / PostgreSQL，适合查询、过滤、排序。
语义索引：向量库或 SQLite + embedding 表。
图记忆：Zep/Graphiti，适合实体、关系、事实有效期。
```

### 学长：记忆组件优化 — 子模块化、BGE-M3 embedding、LLM驱动记忆更新
#### 架构重构:

将 engine/modules/memory.py 单文件拆分为 memory/ 子包  
_types.py: 枚举与数据类 (MemoryScope, MemoryItem, MemoryUpdateAction 等)  
_utils.py: 内部工具函数 (tokenize, cosine, summarize 等)  
base.py: MemoryStore ABC + NoOpMemoryStore  
embedding.py: EmbeddingModel Protocol + HashingEmbeddingModel + BGEM3EmbeddingModel  
judge.py: MemoryLLMJudge Protocol + OpenAIMemoryJudge  
store.py: HybridTieredMemoryStore 完整实现  
init.py: 聚合导出，保持向后兼容  
#### 新功能:  

BGE-M3 稠密向量 embedding (FlagEmbedding, 1024维)  
mem0 风格记忆更新: 检索相似记忆 → LLM 判断动作 (ADD/UPDATE/DELETE/NOOP)  
新增 memory_search_min_similarity 参数过滤低相似度候选  

#### 质量修复:  

提取 _dispatch_write 公共方法消除路由逻辑重复  
_check_and_update_memory 改为优先级策略 (UPDATE > DELETE > ADD)  
SQLite 改用持久连接 + WAL journal mode  
Redis delete 改用 scan_iter 避免 keys() 阻塞  
WORKING 级实现真正 LRU (读取时 move_to_end)  
_find_similar_in_scope 添加相似度阈值过滤 (默认 0.3)
