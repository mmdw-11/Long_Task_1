## 7.10改完上下文和压缩后的情况
第一版这样做的：

```text
WORKING -> Python dict / LRU cache
TASK -> SQLite
PROJECT -> Markdown 原文 + SQLite 索引
GLOBAL -> SQLite / Redis / 可选 Mem0/Zep
```

第二版再扩展每层的内部路由：

```text
热数据：进程内 dict，最快，生命周期短。
温数据：Redis，适合多进程共享和 TTL。
冷数据：Markdown / JSONL 文件，适合人工可读、版本管理、审计。
结构化数据：SQLite / PostgreSQL，适合查询、过滤、排序。
语义索引：向量库或 SQLite + embedding 表。
图记忆：Zep/Graphiti，适合实体、关系、事实有效期。
```
