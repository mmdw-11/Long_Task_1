## 2. 当前端边云实现方式

端边云三类标签：

- `0 = device`
- `1 = edge`
- `2 = cloud`

训练标签不是人工凭感觉标的，而是通过真实三路回答生成：

1. device：`qwen2.5:0.5b-instruct`
2. edge：`qwen2.5:3b-instruct`
3. cloud：`deepseek-v4-flash`
4. cloud judge 比较三路答案质量，并按“满足质量阈值的最低成本层”选择最终 label

执行相关代码：

- device 执行器：`engine/modules/execution/executors.py::LocalModelExecutor`
- edge 执行器：`engine/modules/execution/executors.py::EdgeHttpExecutor`
- edge Ollama HTTP 包装服务：`examples/edge_cloud_scheduler/edge_ollama_server.py`
- cloud 执行器：`engine/modules/execution/executors.py::OpenAICompatibleCloudExecutor`
- 调度器：`engine/modules/scheduling/scheduler.py`
- 生产路由加载：`engine/modules/scheduling/production.py`

## 5. 当前确定的对比学习方案

目标：

- BGE-M3 主干不再完全冻结，而是使用对比学习微调 embedding 空间
- 同 label prompt 拉近
- 不同 label prompt 拉远
- 微调后再训练 MLP 分类头

对比学习数据形式：

```text
anchor   = 当前 prompt
positive = 同 label 的另一个 prompt
negative = 不同 label 的 prompt
```

训练脚本：

```text
examples/router_learning/contrastive_bge_train.py
```

输出目录：

```text
runs/router_learning/final_bge_m3_contrastive_epoch12/
```

关键输出文件：

```text
runs/router_learning/final_bge_m3_contrastive_epoch12/triplets.jsonl
runs/router_learning/final_bge_m3_contrastive_epoch12/contrastive_checkpoints/
runs/router_learning/final_bge_m3_contrastive_epoch12/contrastive_state.json
runs/router_learning/final_bge_m3_contrastive_epoch12/encoder/
runs/router_learning/final_bge_m3_contrastive_epoch12/router/classifier.pkl
runs/router_learning/final_bge_m3_contrastive_epoch12/router/summary.json
runs/router_learning/final_bge_m3_contrastive_epoch12/summary.json
```

其中：

- `contrastive_checkpoints/`：epoch 内断点续训
- `contrastive_state.json`：记录已完成 epoch、best f1、早停状态
- `encoder/`：对比学习微调后的 BGE-M3 encoder
- `router/classifier.pkl`：基于微调后 encoder 训练的 MLP 分类头
- `summary.json`：最终实验指标汇总

## 7. GPU 首次启动命令

在 Linux/JupyterLab Terminal 中：

```bash
cd /data/public/router_gpu_train

export HF_HOME=/data/public/hf_cache
export TRANSFORMERS_CACHE=/data/public/hf_cache/transformers
export HF_HUB_CACHE=/data/public/hf_cache/hub
export HF_DATASETS_CACHE=/data/public/hf_cache/datasets
export TORCH_HOME=/data/public/hf_cache/torch
export TMPDIR=/data/public/tmp
export WANDB_DISABLED=true

python examples/router_learning/contrastive_bge_train.py \
  --dataset runs/router_learning/final_tier_labeled_dataset.deduped.jsonl \
  --base-model BAAI/bge-m3 \
  --output-dir runs/router_learning/final_bge_m3_contrastive_epoch12 \
  --train-ratio 0.8 \
  --hf-home /data/public/hf_cache \
  --epochs 12 \
  --batch-size 8 \
  --learning-rate 0.00002 \
  --warmup-ratio 0.1 \
  --max-triplets 3000 \
  --triplets-per-anchor 2 \
  --triplet-margin 0.5 \
  --checkpoint-save-steps 25 \
  --checkpoint-save-total-limit 5 \
  --early-stop-patience 3 \
  --eval-train-limit 600 \
  --eval-batch-size 16 \
  --mlp-hidden-sizes 512,128 \
  --mlp-max-iter 300 2>&1 | tee runs/router_learning/final_bge_m3_contrastive_epoch12.train.log
```
