按下面顺序运行即可。假设已在后端目录：

```powershell
cd D:\PythonProject\long_task_1\long_task_1
```

1. 激活 Lang_Task，并固定本地 BGE 模型路径：

```powershell
conda activate Lang_Task

$env:BGE_M3_MODEL_PATH = "D:\PythonProject\hf_cache\models\BAAI--bge-m3"
$env:HF_HOME = "D:\PythonProject\hf_cache"
```

2. 检查云模型和 BGE，不输出 Key：

```powershell
python -c "from dotenv import load_dotenv; import os; load_dotenv(); print({'cloud_url': bool(os.getenv('OPENAI_BASE_URL')), 'cloud_key': bool(os.getenv('OPENAI_API_KEY')), 'model': os.getenv('OPENAI_MODEL')})"

python -c "from engine.modules.memory import BGEM3EmbeddingModel; m=BGEM3EmbeddingModel(device='cpu', batch_size=1); print(len(m.embed('wifi state recovery tool skill')))"
```

第二条应输出 `1024`。

3. 验证 ToolSandbox 官方场景可导入：

```powershell
python -c "from tool_sandbox.common.tool_discovery import ToolBackend; from tool_sandbox.scenarios import named_scenarios; print(len(named_scenarios(ToolBackend.DEFAULT)))"
```

4. 准备新的实验输出目录与人工技能库：

```powershell
$root = "runs\experiments\toolsandbox_hard_v5"

python examples\experiments\prepare_toolsandbox_manual_skills.py `
  --output-root $root\skills
```

5. 先跑 3 条真实 canary，只验证 ToolSandbox、云模型、BGE、轨迹与状态哈希是否完整：

```powershell
python examples\experiments\run_toolsandbox_skill_experiment.py `
  --dataset data\processed\toolsandbox_hard_v4\tasks.jsonl `
  --split canary `
  --methods no_skill manual_skill `
  --trials 1 `
  --output-root $root\canary `
  --skill-root $root\skills `
  --skill-budget-chars 6000 `
  --model $env:OPENAI_MODEL `
  --task-timeout 300
```

6. 审计 canary：

```powershell
python examples\experiments\audit_toolsandbox_results.py `
  $root\canary `
  --expected-runs 6 `
  --strict
```

通过条件：

- `status: PASS`
- `rows: 6`、`unique_keys: 6`
- `errors: 0`
- `state_hash_mismatches: 0`
- `missing_final_state_hash: 0`
- `missing_trajectory_hash: 0`
- 每条含真实 token、耗时、ToolSandbox trajectory。

7. canary 通过后，采集训练轨迹。注意：这一步只跑 No Skill，避免训练阶段注入技能：

```powershell
python examples\experiments\run_toolsandbox_skill_experiment.py `
  --dataset data\processed\toolsandbox_hard_v4\tasks.jsonl `
  --split skill_train `
  --methods no_skill `
  --trials 1 `
  --output-root $root\train `
  --skill-root $root\skills `
  --skill-budget-chars 6000 `
  --model $env:OPENAI_MODEL `
  --task-timeout 300
```

8. 从真实成功训练轨迹中让 LLM 归纳自动技能：

```powershell
python examples\experiments\induce_toolsandbox_skills.py `
  --dataset data\processed\toolsandbox_hard_v4\tasks.jsonl `
  --collection-root $root\train `
  --output-root $root\skills `
  --model $env:OPENAI_MODEL `
  --min-training-milestone 0.8
```

9. 在独立 validation 集做真实状态回放；只有通过的技能能进入 `ours_full`：

```powershell
python examples\experiments\validate_toolsandbox_skills.py `
  --dataset data\processed\toolsandbox_hard_v4\tasks.jsonl `
  --skill-root $root\skills `
  --output-root $root\validation `
  --model $env:OPENAI_MODEL `
  --skill-budget-chars 6000
```

10. 通过 validation 后，跑 6 条 pilot、四种方法，共 24 次真实运行：

```powershell
python examples\experiments\run_toolsandbox_skill_experiment.py `
  --dataset data\processed\toolsandbox_hard_v4\tasks.jsonl `
  --split pilot `
  --methods no_skill manual_skill ours_no_validation ours_full `
  --trials 1 `
  --output-root $root\pilot `
  --skill-root $root\skills `
  --skill-budget-chars 6000 `
  --model $env:OPENAI_MODEL `
  --task-timeout 300
```

11. 最后严格审计 pilot：

```powershell
python examples\experiments\audit_toolsandbox_results.py `
  $root\pilot `
  --expected-runs 24 `
  --strict
```

不要在 canary、train、validation、pilot 中使用 `--fresh` 覆盖已有 rows；中断后用完全相同的命令重跑即可断点续跑。
