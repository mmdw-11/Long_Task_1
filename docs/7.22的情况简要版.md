## 二、BGE-M3模型训练的数据集准备
- 使用数据集：https://huggingface.co/datasets/lmsys/chatbot_arena_conversations
- 
该数据集本身的原始语义是：

- 同一个用户问题
- 两个 Arena 模型分别回答
- 用户投票选择更好的回答

但是在本项目中，**不直接使用 LMSYS 的 `winner` 作为路由标签**。

原因：

- LMSYS 的 `winner` 表示“两个已有模型回答谁更好”
- 本项目需要的是“这个用户请求应该分配到 device / edge / cloud 哪一档”

因此，本项目到目前为止使用 LMSYS 数据的方式是：

- 用AI拉下LMSYS中的用户 prompt
- 端、边、云三档模型重新回答这些 prompt
- 再由 judge【云端模型glm-5.2】 评估三档回答质量进行打分，然后标注数据集
