新增指标：

- 检索上下文 token 估算；

同时修复了记忆更新路径中的一个实际问题：LLM Judge 返回 `ADD` 时，旧实现的返回值会使新记忆被当成“已处理”而跳过写入；现已改为继续正常写入，并添加 per-store 动作计数。

注意：当前 No Memory、Full-Context 和 memory runner 评估的是“标准答案是否出现在可见/检索记忆中”，不是完整生成式 QA。正式论文必须明确这一评估边界。
